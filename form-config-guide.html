SPECS Signup Form - Backend Configuration Options

Option 1: Formspree (Recommended)

Best for: Simple setup, reliable form handling, built-in spam protection

Setup Steps:

  1. Go to formspree.io and create a free account
  2. Create a new form project
  3. Replace "YOUR_FORM_ID" with your actual form ID in index.html
  4. Deploy and test

Form HTML:

<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
    <!-- form fields -->
    <input type="hidden" name="_subject" value="New SPECS Club Signup">
    <input type="hidden" name="_next" value="https://yoursite.github.io/website/#signup-success">
</form>
Data Access: View submissions in Formspree dashboard, export as CSV, set up email notifications

Option 2: Google Forms Integration

Best for: Familiar Google ecosystem, automatic spreadsheet storage

Setup Steps:

  1. Create a Google Form with matching fields
  2. Get the form action URL and field IDs
  3. Update the form to post to Google Forms

Form HTML Example:

<form action="https://docs.google.com/forms/d/FORM_ID/formResponse" method="POST">
    <input name="entry.123456789" placeholder="First Name" required>
    <input name="entry.987654321" placeholder="Last Name" required>
    <input name="entry.555666777" type="email" placeholder="Email" required>
    <!-- more fields with their respective entry IDs -->
</form>
Data Access: Automatic Google Sheets integration, real-time collaboration, easy data analysis

Option 3: EmailJS

Best for: Email-based submissions, no external database needed

Setup Steps:

  1. Create account at emailjs.com
  2. Connect your email service (Gmail, Outlook, etc.)
  3. Create an email template
  4. Replace form submission with EmailJS call

JavaScript Example:

// Include EmailJS SDK
<script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@3/dist/email.min.js"></script>

// Form submission
emailjs.sendForm('service_id', 'template_id', form, 'public_key')
    .then(() => console.log('SUCCESS!'))
    .catch((error) => console.log('FAILED...', error));
Data Access: All submissions sent as emails, can be filtered and organized in email client

Option 4: Netlify Forms (If migrating from GitHub Pages)

Best for: If considering a move to Netlify hosting

Setup:

<form netlify name="specs-signup">
    <!-- form fields -->
</form>
Note: Only works with Netlify hosting, not GitHub Pages
